La lezione serve per verificare che il tuo ambiente di sviluppo funzioni correttamente e per mostrarti come modificare i file principali di un’app Angular per visualizzare il testo “Hello world!”.


🌱 Obiettivo della lezione

La prima lezione del tutorial Angular ti guida a:

    - scaricare il progetto iniziale;
    - avviare l’app Angular di default;
    - capire la struttura dei file principali;
    - modificare il componente principale per mostrare “Hello world!”.

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

📦 1. Scaricare l’app di partenza

La pagina ti chiede di:

    - cliccare sull’icona Download nell’editor (se usi l’editor integrato del sito);
    - estrarre lo ZIP;
    - aprire il progetto nel tuo IDE (VS Code, WebStorm, ecc.).

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

▶️ 2. Avviare l’app Angular

Nel terminale del tuo IDE:

    1. Vai nella cartella del progetto, ad esempio:
    cd first-app

    2. Installa le dipendenze:
    npm install

    3. Avvia il server di sviluppo:
    ng serve

Poi apri il browser su http://localhost:4200.
Dovresti vedere l’app Angular di default.

------------------------------------------------------------------------------------------------------------------------------------------------------

📁 3. Capire la struttura dei file

La lezione ti mostra i file più importanti:
File / Cartella	         Funzione
src/index.html	         Template HTML principale dell’app
src/styles.css	         Foglio di stile globale
src/main.ts	             Punto di ingresso dell’app
src/app/app.ts	         Componente principale (app-root)
src/app/app.css	         Stili del componente principale
assets/	                 Immagini e risorse statiche
angular.json	         Configurazione del progetto
package.json	         Dipendenze e script npm

-----------------------------------------------------------------------------------------------------------------------------------------

✏️ 4. Modificare l’app per mostrare “Hello world!”

La parte centrale della lezione:
🔹 Modifica del titolo in index.html

Apri src/index.html e cambia il contenuto del tag <title>:
html

<title>Homes</title>

(È solo un esempio per verificare che la modifica funzioni.)
🔹 Modifica del componente principale in app.ts

Apri src/app/app.ts e sostituisci la proprietà template con:
ts

template: `
  <h1>Hello world!</h1>
`,

E aggiorna anche la proprietà title se richiesto.

---------------------------------------------------------------------------------------------------------------------------------------

🌐 5. Verifica nel browser

Se ng serve è ancora attivo, la pagina si aggiorna automaticamente.
Vai su http://localhost:4200 e dovresti vedere:

    - Titolo della pagina: Homes
    - Testo nel corpo: Hello world!

✅ Cosa hai imparato

    - Come avviare un’app Angular.
    - Come è organizzato un progetto Angular.
    - Come modificare il componente principale.
    - Come far apparire “Hello world!” nell’app.

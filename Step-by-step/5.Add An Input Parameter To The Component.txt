Perfetto, andiamo avanti con la lezione 05 – Inputs, una delle più importanti dell’intero tutorial perché introduce il meccanismo che permette ai componenti Angular di ricevere dati dall’esterno.
Questa parte completa ciò che hai iniziato nella lezione precedente con HousingLocationComponent.


🎯 Obiettivo della lezione

La sezione Inputs ti insegna a:

    - dichiarare proprietà di input in un componente figlio;
    - passare dati dal componente genitore al figlio;
    - usare il decoratore @Input() in modo corretto;
    - tipizzare gli input con l’interfaccia creata in precedenza.

----------------------------------------------------------------------------------------------------------------------------------------------------

🧩 1. Aggiungere un input al componente figlio

Nel componente HousingLocationComponent, il tutorial ti fa aggiungere:
ts

@Input() housingLocation!: HousingLocation;

Cosa significa:

    @Input() dice ad Angular: questa proprietà può ricevere un valore dal componente genitore.

    housingLocation è il nome della proprietà.

    ! indica a TypeScript che il valore arriverà sicuramente (evita errori di “possibly undefined”).

---------------------------------------------------------------------------------------------------------------------------------------------------------

🧱 2. Usare l’input nel template del componente figlio

Ora il template può accedere ai dati ricevuti:
html

<section class="listing">
  <img [src]="housingLocation.photo" alt="Photo of {{ housingLocation.name }}">
  <h2>{{ housingLocation.name }}</h2>
  <p>{{ housingLocation.city }}, {{ housingLocation.state }}</p>
</section>

Concetti chiave:

    - [src]="housingLocation.photo" → property binding.
    - {{ housingLocation.name }} → interpolazione.
    - Il componente figlio non ha più dati propri: li riceve dal genitore.

---------------------------------------------------------------------------------------------------------------------------------------

🔗 3. Passare i dati dal componente genitore

Nel componente HomeComponent, dove hai la lista delle case, aggiorni il template:
html

<ul>
  <li *ngFor="let home of housingLocationList">
    <app-housing-location
      [housingLocation]="home">
    </app-housing-location>
  </li>
</ul>

Cosa succede:

   - *ngFor cicla sugli oggetti della lista.
   - Ogni oggetto home viene passato al figlio tramite [housingLocation]="home".

È esattamente come passare un “argomento” a una funzione, ma tra componenti.

-------------------------------------------------------------------------------------------------------

🧠 4. Perché gli input sono fondamentali

Gli input permettono di:
    - creare componenti riutilizzabili;
    - separare la logica dalla presentazione;
    - costruire interfacce complesse composte da tanti componenti piccoli;
    - mantenere un flusso dati chiaro e unidirezionale.

In Angular, i dati scendono dal genitore al figlio tramite @Input().

----------------------------------------------------------------------------------------------------------------

🧪 5. Risultato della lezione

Alla fine di questa sezione:

    - HousingLocationComponent è un componente riutilizzabile che mostra una singola casa.
    - HomeComponent gli passa i dati tramite input.

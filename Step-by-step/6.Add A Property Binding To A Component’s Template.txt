Perfetto, continuiamo con la lezione 06 – Property binding, una delle più importanti per capire come Angular collega i dati del componente all’interfaccia grafica.
Questa sezione ti mostra come usare il property binding per impostare valori dinamici sugli attributi HTML, come src, alt, disabled, value, ecc.


🔌 Cos’è il property binding

Il property binding ti permette di collegare una proprietà di un elemento HTML o di un componente al valore di una variabile del tuo componente TypeScript.

La sintassi è:
html

[elementProperty]="componentProperty"

Esempi comuni:
    - [src]="imageUrl"
    - [disabled]="isDisabled"
    - [value]="username"


🧩 1. Applicazione al progetto: mostrare l’immagine della casa

Nel componente HousingLocationComponent, il tutorial ti fa aggiornare l’immagine così:
html

<img
  [src]="housingLocation.photo"
  alt="Exterior photo of {{ housingLocation.name }}"
>

Cosa succede:

    [src] è property binding → Angular imposta la proprietà src dell’elemento <img> usando il valore di housingLocation.photo.

    {{ housingLocation.name }} è interpolazione → Angular inserisce il testo dentro l’attributo alt.


🧠 Perché usare il property binding invece dell’interpolazione?

Potresti pensare che si possa fare:
html

<img src="{{ housingLocation.photo }}">

Funziona, ma non è consigliato.

Motivi:

    [src] è più chiaro e più performante.

    Angular assegna direttamente la proprietà dell’elemento, non una stringa HTML.

    Evita problemi con valori complessi (booleani, numeri, oggetti).

-------------------------------------------------------------------------------------------------------------------------

🧱 2. Property binding con valori booleani

Il tutorial mostra anche che puoi usare property binding con attributi booleani.

Esempio:
html

<button [disabled]="!housingLocation.availableUnits">
  Reserve
</button>

Se availableUnits è 0 → il bottone diventa disabilitato.

--------------------------------------------------------------------------------------------------------------------

🧭 3. Property binding vs interpolazione

Una tabella per chiarire:
Caso	Interpolazione {{ }}	Property binding [ ]
Inserire testo	✔️	❌
Impostare proprietà HTML	❌	✔️
Impostare attributi booleani	❌	✔️
Impostare valori dinamici complessi	⚠️	✔️
Usare in alt, title, aria-*	✔️	✔️

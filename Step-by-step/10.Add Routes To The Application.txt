Perfetto, arriviamo alla lezione 10 – Routing, una delle più importanti perché introduce la navigazione tra pagine nella tua app Angular.
Finora hai una sola pagina (Home), ma ora aggiungerai la pagina dei dettagli di una casa e imparerai come spostarti da una vista all’altra.


🧭 Obiettivo della lezione

Questa sezione ti insegna a:

    - configurare il router di Angular;
    - creare una pagina di dettaglio per una singola casa;
    - usare parametri dinamici nell’URL (es. /details/3);
    - navigare tramite link.

È il momento in cui la tua app diventa una vera SPA (Single Page Application).

-------------------------------------------------------------------------------------------------------------
🧩 1. Creare la pagina dei dettagli

Il tutorial ti fa creare un nuovo componente:
src/app/details/details.component.ts

Esempio semplificato:
ts

import { Component } from '@angular/core';

@Component({
  selector: 'app-details',
  standalone: true,
  template: `
    <section>
      <h2>Housing Details</h2>
    </section>
  `,
})
export class DetailsComponent {}

Questa sarà la pagina che mostra le informazioni di una singola casa.

--------------------------------------------------------------------------------------------------------------------------

🗺️ 2. Configurare il router

Angular 17+ usa un router molto più semplice grazie ai componenti standalone.

Nel file main.ts aggiungi:
ts

import { bootstrapApplication } from '@angular/platform-browser';
import { provideRouter } from '@angular/router';
import { AppComponent } from './app/app.component';
import { routes } from './app/app.routes';

bootstrapApplication(AppComponent, {
  providers: [
    provideRouter(routes)
  ]
});

Poi crei il file delle rotte:
src/app/app.routes.ts

Con qualcosa del genere:
ts

import { Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { DetailsComponent } from './details/details.component';

export const routes: Routes = [
  { path: '', component: HomeComponent },
  { path: 'details/:id', component: DetailsComponent }
];

Cosa impari:

    - path: '' → pagina principale.
    - path: 'details/:id' → rotta con parametro dinamico.
    - :id rappresenta l’identificativo della casa.

------------------------------------------------------------------------------------------------------------------------------------

🔗 3. Aggiungere un link alla pagina dei dettagli

Nel componente HousingLocationComponent, aggiungi un link:
html

<a [routerLink]="['/details', housingLocation.id]">
  Learn more
</a>

Cosa succede:
    - Angular costruisce l’URL /details/ID.
    - Cliccando, il router carica DetailsComponent.

--------------------------------------------------------------------------------------------------------------------

📥 4. Recuperare il parametro id nella pagina dei dettagli

Nel componente DetailsComponent, usi ActivatedRoute per leggere l’ID dalla URL:
ts

import { Component } from '@angular/core';
import { ActivatedRoute } from '@angular/router';
import { HousingService } from '../housing.service';

@Component({
  selector: 'app-details',
  standalone: true,
  templateUrl: './details.component.html',
})
export class DetailsComponent {
  constructor(
    private route: ActivatedRoute,
    private housingService: HousingService
  ) {}

  housingLocation = this.housingService.getHousingLocationById(
    Number(this.route.snapshot.params['id'])
  );
}

Concetti chiave:
    - ActivatedRoute → permette di leggere i parametri dell’URL.
    - snapshot.params['id'] → ottieni l’ID.
    - Il servizio recupera i dati della casa corrispondente.

-----------------------------------------------------------------------------------------------------------------

🖼️ 5. Mostrare i dettagli nel template

Ora il template può mostrare i dati:
html

<section *ngIf="housingLocation">
  <h2>{{ housingLocation.name }}</h2>
  <img [src]="housingLocation.photo">
  <p>{{ housingLocation.city }}, {{ housingLocation.state }}</p>
</section>

-----------------------------------------------------------------------------------------------------------

🎯 Risultato della lezione

Dopo questa sezione:
    - la tua app ha due pagine: Home e Details;
    - puoi navigare tra le pagine senza ricaricare il browser;

hai imparato a usare:
        - il router,
        - i parametri dinamici,
        - i link con routerLink,
        - i servizi per recuperare i dati.

La tua app ora è una vera SPA moderna.

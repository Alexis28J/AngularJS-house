Perfetto, arriviamo alla lezione 14 – HTTP, una delle più importanti perché trasforma la tua app da un progetto statico a un’app capace di recuperare dati da un server.
Finora i dati delle case erano hardcoded nel servizio. Ora imparerai a:

    - usare HttpClient;
    - caricare i dati da un file JSON remoto;
    - rendere il servizio asincrono;
    - aggiornare i componenti per usare Observable.

È un passo fondamentale verso un’app reale.


🌐 Obiettivo della lezione

Questa sezione ti insegna a:
    - importare HttpClientModule;
    - usare HttpClient nel servizio;
    - recuperare dati da un endpoint (mock);
    - aggiornare i componenti per gestire dati asincroni.

----------------------------------------------------------------------------------------------

🧩 1. Abilitare HttpClient

Nel file main.ts, aggiungi il provider:
ts

import { provideHttpClient } from '@angular/common/http';

bootstrapApplication(AppComponent, {
  providers: [
    provideRouter(routes),
    provideHttpClient()
  ]
});

Questo rende HttpClient disponibile in tutta l’app.

-----------------------------------------------------------------------------------------------------

📡 2. Aggiornare il servizio per usare HTTP

Nel file housing.service.ts, sostituisci i dati statici con una chiamata HTTP.

Esempio:
ts

import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { HousingLocation } from './housinglocation';

@Injectable({
  providedIn: 'root'
})
export class HousingService {
  constructor(private http: HttpClient) {}

  url = 'https://angular.dev/assets/housing.json';

  getAllHousingLocations() {
    return this.http.get<HousingLocation[]>(this.url);
  }

  getHousingLocationById(id: number) {
    return this.http.get<HousingLocation>(`${this.url}/${id}`);
  }
}

Cosa cambia:
    - HttpClient restituisce Observable, non valori immediati.
    - I dati arrivano in modo asincrono.
    - Il servizio non contiene più dati hardcoded.

--------------------------------------------------------------------------------------------------------------------------

🔄 3. Aggiornare HomeComponent per gestire Observable

Prima:
ts

this.housingLocationList = this.housingService.getAllHousingLocations();

Ora:
ts

this.housingService.getAllHousingLocations()
  .subscribe(locations => {
    this.housingLocationList = locations;
    this.filteredLocationList = locations;
  });

Concetti introdotti:
    - subscribe() → riceve i dati quando arrivano.
    - Il componente non deve sapere come funziona HTTP, solo che riceve dati.

-------------------------------------------------------------------------------------------------------------------------------

🏠 4. Aggiornare DetailsComponent

Anche la pagina dei dettagli deve usare HTTP:
ts

const housingLocationId = Number(this.route.snapshot.params['id']);

this.housingService.getHousingLocationById(housingLocationId)
  .subscribe(location => {
    this.housingLocation = location;
  });

🧠 5. Perché questo è importante

Ora la tua app:
    - può caricare dati da un server;
    - è pronta per un backend reale (Node, .NET, Firebase, ecc.);
    - usa pattern asincroni moderni;
    - separa completamente UI e dati.

È un enorme passo verso un’app professionale.

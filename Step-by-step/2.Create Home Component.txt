La lezione “Home” del tutorial Angular introduce il tuo primo componente reale: HomeComponent. 
Imparerai a crearlo, collegarlo all’app e visualizzare una lista di case (mock) nella pagina principale.


🏡 Obiettivo della lezione

La pagina 02‑Home ti guida a:

    creare un nuovo componente Angular chiamato HomeComponent;

    aggiungerlo all’app come pagina principale;

    preparare una piccola lista di dati (mock) da mostrare;

    visualizzare questi dati nel template tramite property binding e interpolazione.

--------------------------------------------------------------------------------------------------------------------------------------------------------
🧩 1. Creazione del componente Home

Il tutorial ti fa creare un file home.component.ts (o home.ts nella nuova struttura semplificata di Angular 17+).

Il componente è simile a questo:
ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-home',
  standalone: true,
  template: `
    <section>
      <h2>Homes</h2>
    </section>
  `,
})
export class HomeComponent {}


Cosa impari qui:
    - standalone: true → i componenti non richiedono più moduli.
    - selector → il tag HTML che rappresenta il componente.
    - template → il markup che verrà mostrato nella pagina.

--------------------------------------------------------------------------------------------------------------------------------------------------

🔗 2. Collegare HomeComponent all’app

Nel file app.ts (il componente root), devi importare e usare il nuovo componente:
ts

import { Component } from '@angular/core';
import { HomeComponent } from './home/home.component';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [HomeComponent],
  template: `
    <app-home></app-home>
  `,
})
export class AppComponent {}

Cosa succede:  
Il componente principale ora mostra <app-home>, quindi la tua app visualizza la pagina Home.

-----------------------------------------------------------------------------------------------------------------------------------------------

📦 3. Aggiungere dati mock (lista di case)

Il tutorial introduce un array di oggetti che rappresentano case in vendita/affitto.

Esempio:
ts

homes = [
  {
    id: 1,
    name: 'Casa al mare',
    image: 'assets/house1.jpg',
    price: 120000
  },
  {
    id: 2,
    name: 'Appartamento in città',
    image: 'assets/house2.jpg',
    price: 200000
  }
];

Questi dati vengono inseriti dentro HomeComponent.

--------------------------------------------------------------------------------------------------------------------------------

🖼️ 4. Visualizzare i dati nel template

Il template viene aggiornato per mostrare la lista:
html

<section>
  <h2>Homes</h2>

  <ul>
    <li *ngFor="let home of homes">
      <img [src]="home.image" alt="">
      <h3>{{ home.name }}</h3>
      <p>Price: {{ home.price }}</p>
    </li>
  </ul>
</section>

Concetti introdotti:

    *ngFor → direttiva per iterare sugli array.

    [src]="home.image" → property binding.

    {{ home.name }} → interpolazione.

----------------------------------------------------------------------------------------------------------------------------   

🎯 5. Risultato finale

Visitando http://localhost:4200, ora vedi:

    un titolo “Homes”;

    una lista di case con immagine, nome e prezzo.

Hai creato la tua prima pagina vera e propria in Angular!

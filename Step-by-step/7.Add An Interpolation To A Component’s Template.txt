Perfetto, proseguiamo con la lezione 07 – Dynamic template values, una tappa importante perché ti mostra come rendere il template dinamico usando i dati del componente.
Questa sezione completa ciò che hai iniziato con property binding e interpolazione, ma lo porta un passo avanti: impari a combinare valori, trasformarli e usarli direttamente nel template.


🎯 Obiettivo della lezione

La lezione ti insegna a:
    - usare valori dinamici nel template;
    - combinare proprietà dell’oggetto HousingLocation;
    - mostrare testo derivato dai dati;
    - capire meglio interpolazione e property binding insieme.

---------------------------------------------------------------------------------------------------------------------------------------------------

🧩 1. Interpolazione dinamica nel template

Il tutorial ti fa aggiornare il template di HousingLocationComponent per mostrare informazioni più ricche.

Esempio tipico:
html

<p>{{ housingLocation.city }}, {{ housingLocation.state }}</p>

Qui stai combinando due proprietà dell’oggetto per creare una stringa più leggibile.

------------------------------------------------------------------------------------------------------------------------------

🧠 2. Usare espressioni nel template

Angular permette di usare piccole espressioni direttamente dentro {{ }}.

Esempi:
html

<p>Available units: {{ housingLocation.availableUnits > 0 ? 'Yes' : 'No' }}</p>

Oppure:
html

<p>{{ housingLocation.wifi ? 'Wi‑Fi included' : 'No Wi‑Fi' }}</p>

Regola importante:  
Le espressioni devono essere semplici.
Niente funzioni complesse, niente logica pesante.

-----------------------------------------------------------------------------------------------------------------------------------

🖼️ 3. Property binding con valori dinamici

Il tutorial ti mostra anche come usare valori dinamici con property binding.

Esempio:
html

<img
  [src]="housingLocation.photo"
  alt="Exterior photo of {{ housingLocation.name }}"
>

Qui hai:

    - [src] → property binding dinamico
    - {{ housingLocation.name }} → interpolazione dinamica

-------------------------------------------------------------------------------------------------------------------------------

🧱 4. Combinare dinamicamente testo e proprietà

Un altro esempio tipico della lezione:
html

<h2>{{ housingLocation.name }}</h2>
<p>{{ housingLocation.city }}, {{ housingLocation.state }}</p>

Stai costruendo una frase usando i dati dell’oggetto.

-------------------------------------------------------------------------------------------------------------------------------------

🧭 5. Perché questa lezione è importante

Questa sezione ti prepara a:
    - creare template più intelligenti;
    - mostrare informazioni derivate dai dati;
    - rendere i componenti più espressivi senza aggiungere logica inutile nel TypeScript.

È un passo fondamentale prima di introdurre:
    - event binding (interazioni dell’utente),
    - routing (navigazione),
    - servizi (gestione dei dati).

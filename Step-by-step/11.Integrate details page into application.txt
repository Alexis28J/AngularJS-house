La pagina Integrate details page into application completa il lavoro iniziato con il routing.


🎯 Obiettivo della lezione

Questa pagina ti guida a:

    collegare la pagina dei dettagli (DetailsComponent) alla lista delle proprietà

    recuperare l’ID della proprietà dalla rotta

    usare il servizio per ottenere i dati della singola casa

    mostrare i dettagli nel template

Dopo questa lezione, la tua app avrà una navigazione completa: Home → Details.


🧱 1. Preparare il servizio per ottenere una singola proprietà

Apri:
src/app/housing.service.ts

La pagina ti fa aggiungere un metodo simile:
ts

getHousingLocationById(id: number): HousingLocation | undefined {
  return this.housingLocationList.find(h => h.id === id);
}

Questo metodo:

    riceve un ID

    cerca la proprietà corrispondente

    restituisce l’oggetto HousingLocation


🧭 2. Recuperare l’ID dalla rotta nel DetailsComponent

Apri:
src/app/details/details.component.ts

La pagina ti fa:
✔️ importare ActivatedRoute

Serve per leggere i parametri dell’URL.
✔️ iniettare il servizio e ActivatedRoute nel costruttore
ts

constructor(
  private route: ActivatedRoute,
  private housingService: HousingService
) {}

✔️ leggere l’ID dalla rotta
ts

const housingLocationId = Number(this.route.snapshot.params['id']);

✔️ ottenere i dati dal servizio
ts

this.housingLocation = this.housingService.getHousingLocationById(housingLocationId);

Ora il componente ha i dati della casa selezionata.


🧩 3. Mostrare i dati nel template

Apri:
src/app/details/details.component.html

La pagina ti fa aggiungere interpolazioni come:
html

<h2>{{ housingLocation?.name }}</h2>
<p>{{ housingLocation?.city }}, {{ housingLocation?.state }}</p>

Il punto interrogativo (?.) evita errori se i dati non sono ancora caricati.


🔗 4. Collegare la Home alla pagina dei dettagli

Ora bisogna aggiungere un link nel componente HousingLocationComponent.

Apri:
src/app/housing-location/housing-location.component.html

e aggiungi un link:
html

<a [routerLink]="['/details', housingLocation.id]">View Details</a>

Questo crea un link dinamico come:
Codice

/details/1
/details/2
/details/3

a seconda della casa.


🧠 5. Cosa stai imparando davvero
✔️ Routing dinamico

Le rotte possono contenere parametri (:id).
✔️ ActivatedRoute

Serve per leggere i parametri dell’URL.
✔️ Comunicazione tra componenti e servizio

Il DetailsComponent chiede i dati al servizio, non alla Home.
✔️ Navigazione completa

L’utente può passare dalla lista alla pagina dei dettagli.
✔️ Template sicuri

L’operatore ?. evita errori quando i dati non sono ancora disponibili.


🖼️ 6. Risultato finale

Dopo questa lezione:

    la Home mostra la lista delle case

    ogni card ha un link “View Details”

    cliccando si apre la pagina dei dettagli

    i dati vengono caricati dal servizio in base all’ID

La tua app ora ha una navigazione reale e completa.

Questa lezione ti guida a mostrare i dettagli completi di una singola casa usando l’ID presente nell’URL.


🧭 Obiettivo della lezione

In questa sezione imparerai a:
    - recuperare l’ID della casa dalla URL;
    - usare il servizio per ottenere i dati completi;
    - mostrare tutte le informazioni nel template;
    - aggiungere un form di contatto (che verrà completato nella lezione successiva).

-----------------------------------------------------------------------------------------------------------------------------------

🧩 1. Recuperare l’ID dalla URL

Quando l’utente clicca su “Learn more”, viene portato a una rotta come:
/details/3

Nel componente DetailsComponent, devi leggere questo parametro.

Esempio:
ts

import { Component } from '@angular/core';
import { ActivatedRoute } from '@angular/router';
import { HousingService } from '../housing.service';
import { HousingLocation } from '../housinglocation';

@Component({
  selector: 'app-details',
  standalone: true,
  templateUrl: './details.component.html',
})
export class DetailsComponent {
  housingLocation!: HousingLocation;

  constructor(
    private route: ActivatedRoute,
    private housingService: HousingService
  ) {
    const housingLocationId = Number(this.route.snapshot.params['id']);
    this.housingLocation = this.housingService.getHousingLocationById(housingLocationId)!;
  }
}

Cosa succede:
    - ActivatedRoute permette di leggere i parametri dell’URL.
    - snapshot.params['id'] recupera l’ID.
    - Il servizio restituisce l’oggetto corrispondente.

---------------------------------------------------------------------------------------------------------------------------------

🏠 2. Mostrare i dettagli nel template

Il tutorial ti fa aggiornare il template per mostrare tutte le informazioni della casa.

Esempio:
html

<section *ngIf="housingLocation">
  <img [src]="housingLocation.photo" alt="Photo of {{ housingLocation.name }}">
  <h2>{{ housingLocation.name }}</h2>
  <p>{{ housingLocation.city }}, {{ housingLocation.state }}</p>

  <ul>
    <li>Units available: {{ housingLocation.availableUnits }}</li>
    <li>Wi‑Fi: {{ housingLocation.wifi ? 'Yes' : 'No' }}</li>
    <li>Laundry: {{ housingLocation.laundry ? 'Yes' : 'No' }}</li>
  </ul>
</section>

Concetti chiave:
    - *ngIf evita errori se i dati non sono ancora disponibili.
    - Interpolazione e property binding mostrano i valori dinamici.
    - Le proprietà booleane vengono trasformate in testo leggibile.

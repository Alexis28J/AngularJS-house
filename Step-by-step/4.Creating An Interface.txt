Questa parte è breve ma fondamentale: introduce il concetto di interfacce TypeScript per tipizzare i dati della tua app.


🧠 Perché questa lezione è importante

Finora hai usato oggetti “alla buona” per rappresentare le case.
Ora Angular ti invita a definire una struttura formale dei dati, così:

    - il codice diventa più chiaro;
    - l’IDE può aiutarti con l’autocompletamento;
    - eviti errori dovuti a proprietà mancanti o scritte male;
    - i componenti che ricevono dati tramite @Input() diventano più robusti.

----------------------------------------------------------------------------------------------------------------------------------------

📄 1. Creare l’interfaccia HousingLocation

La lezione ti fa creare un file dedicato, ad esempio:
src/app/housinglocation.ts

E dentro ci metti:
ts

export interface HousingLocation {
  id: number;
  name: string;
  city: string;
  state: string;
  photo: string;
  availableUnits: number;
  wifi: boolean;
  laundry: boolean;
}

Cosa rappresenta:  
Una “forma” che ogni oggetto casa deve rispettare.

----------------------------------------------------------------------------------------------------------------

🧱 2. Usare l’interfaccia nei componenti

Ora puoi tipizzare i dati nel componente Home:
ts

import { HousingLocation } from '../housinglocation';

homes: HousingLocation[] = [
  {
    id: 1,
    name: 'Casa al mare',
    city: 'Genova',
    state: 'Liguria',
    photo: 'assets/house1.jpg',
    availableUnits: 2,
    wifi: true,
    laundry: false
  },
  // ...
];

E anche nel componente HousingLocationComponent:
ts

@Input() housingLocation!: HousingLocation;

Vantaggi immediati:

    - se dimentichi una proprietà, TypeScript ti avvisa;
    - se sbagli tipo (es. metti una stringa al posto di un numero), ti avvisa;
    - il codice diventa auto-documentato.

-----------------------------------------------------------------------------------------------------------------------------------------------

🧭 3. Perché il tutorial introduce le interfacce ora

Perché nella prossima lezione inizierai a:

    - spostare i dati in un servizio,
    - recuperare i dati tramite metodi dedicati,
    - passare oggetti tipizzati tra componenti.


Le interfacce sono il collante che mantiene tutto coerente.
🎯 Risultato della lezione

Alla fine di questa sezione hai:

    - un’interfaccia HousingLocation;

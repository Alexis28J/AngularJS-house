Perfetto, continuiamo con la lezione 13 – Search, in cui aggiungi una funzionalità di ricerca alla pagina Home.
Questa parte è molto utile perché rende l’app interattiva e introduce un pattern comune: filtrare una lista in base all’input dell’utente.


🔍 Obiettivo della lezione

In questa sezione imparerai a:
    - aggiungere un campo di ricerca nella pagina Home;
    - collegare l’input dell’utente a una proprietà del componente;
    - filtrare dinamicamente la lista delle case;
    - mostrare solo i risultati che corrispondono al testo inserito.

---------------------------------------------------------------------------------------------------

🧩 1. Aggiungere una lista filtrata nel componente Home

Finora avevi una sola lista: housingLocationList.
Ora ne aggiungi una seconda:
ts

filteredLocationList: HousingLocation[] = [];

Poi, nel costruttore, inizializzi entrambe:
ts

constructor(private housingService: HousingService) {
  this.housingLocationList = this.housingService.getAllHousingLocations();
  this.filteredLocationList = this.housingLocationList;
}

Perché serve una seconda lista?
    - housingLocationList → contiene tutti i dati.
    - filteredLocationList → contiene solo i risultati filtrati.

------------------------------------------------------------------------------------------------------------------

🧠 2. Aggiungere il metodo di ricerca

Nel componente Home aggiungi un metodo che filtra la lista:
ts

filterResults(text: string) {
  if (!text) {
    this.filteredLocationList = this.housingLocationList;
    return;
  }

  this.filteredLocationList = this.housingLocationList.filter(
    location => location.name.toLowerCase().includes(text.toLowerCase())
  );
}

Cosa fa:
    - Se il campo è vuoto → mostra tutte le case.
    - Altrimenti → mostra solo quelle il cui nome contiene il testo inserito.

-----------------------------------------------------------------------------------------------------------

🖼️ 3. Aggiungere il campo di ricerca nel template

Nel file home.component.html, aggiungi un input:
html

<section class="search">
  <input
    type="text"
    placeholder="Search by name"
    #searchInput
  >
  <button (click)="filterResults(searchInput.value)">
    Search
  </button>
</section>

Concetti introdotti:
    - #searchInput → template reference variable (riferimento all’input).
    - (click)="..." → event binding.
    - searchInput.value → valore digitato dall’utente.

------------------------------------------------------------------------------------------------------------------------

🧱 4. Usare la lista filtrata nel template

Aggiorna il tuo *ngFor per usare la lista filtrata:
html

<ul>
  <li *ngFor="let housingLocation of filteredLocationList">
    <app-housing-location
      [housingLocation]="housingLocation">
    </app-housing-location>
  </li>
</ul>

Ora la UI mostra solo i risultati filtrati.

---------------------------------------------------------------------------------------------

🧪 5. Come funziona l’esperienza utente
    - L’utente digita un testo nel campo di ricerca.
    - Clicca su Search.
    - Angular chiama filterResults().
    - La lista filtrata si aggiorna.
    - Il template si aggiorna automaticamente.


🎯 Risultato della lezione

Dopo questa sezione:

    - la tua app ha una ricerca funzionante;
    - la lista delle case si aggiorna dinamicamente;

    hai imparato a usare:

        - template reference variables,
        - event binding,
        - filtering in TypeScript,
        - liste dinamiche con *ngFor.

La tua Home ora è molto più interattiva e utile.
